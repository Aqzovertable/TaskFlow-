# TaskFlow — менеджер задач

**Демонстрационный проект EXADY.** Адаптивная Kanban-доска для личных задач и небольших команд.

## Возможности
- Создание, редактирование и удаление задач.
- Три статуса: к выполнению, в процессе, готово.
- Приоритеты, поиск и счётчики задач.
- Сохранение данных в LocalStorage.
- Адаптивная вёрстка для мобильных и настольных экранов.

## Запуск
Откройте `index.html` в современном браузере. Сборка, сервер и зависимости не требуются.

## Стек
HTML5 · CSS3 · Vanilla JavaScript

## Важно
Это pet/demo-проект. Данные сохраняются только в текущем браузере и не синхронизируются между устройствами.
